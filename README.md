## 项目介绍

闲鱼雷达源于二手电子产品回收与销售的实际需求：把重复搜索、商品筛选和消息通知集中在一个工作台中，减少反复切换页面的操作，方便用户发现和评估目标商品。

本仓库用于展示产品、发布说明和收集反馈。完整商业源码目前保持私有。

## 功能介绍

| 模块 | 说明 |
| --- | --- |
| 多品类搜索 | 围绕显卡、手机、内存和硬盘等电子产品设置搜索任务 |
| 商品工作台 | 集中查看商品信息和筛选结果 |
| 筛选规则 | 按需求配置筛选条件，减少无关商品干扰 |
| 卖家黑名单 | 管理需要排除的卖家 |
| 钉钉通知 | 将关注的商品信息推送到配置的钉钉群 |
| 账号管理 | 在本机管理登录与账号状态 |

具体功能与可用性以实际交付版本为准。

## 使用流程

1. 联系作者，确认所需品类与使用场景。
2. 获取适用的程序版本，按说明完成本地配置。
3. 登录自己的账号，设置搜索任务和筛选规则。
4. 在工作台查看结果，按需配置钉钉通知。
5. 自行核验商品、卖家与交易条件后决定是否购买。

目前不是。本仓库公开产品说明与反馈入口，不提供完整商业源码，也不授予软件的开源使用许可。

### 可以直接从这里下载安装吗？

本仓库目前不提供公开安装包。请通过使用咨询入口联系作者。

### 是否保证每次都能搜到商品、及时收到通知或购买成功？

不保证。搜索结果、登录状态、通知与交易会受到网络、平台状态、账号状态和卖家行为等因素影响。软件不承诺固定收益、购买成功或账号不受限制。

可以。提交前请遮挡账号、联系方式、订单信息、登录凭证及其他个人信息。
